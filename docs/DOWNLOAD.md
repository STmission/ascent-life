# 朋友试玩

网页：https://stmission.github.io/ascent-life/
下载：https://github.com/STmission/ascent-life/releases/latest

## 网页
用现代浏览器打开上面的链接。首次下载约 23 MB 的场景与人物资源，加载完成后开始。存档保存在当前设备和浏览器，清除浏览器数据会丢失存档。

## macOS Apple Silicon
下载 `Ascent-macOS-arm64.zip` 并完整解压。把 `Ascent.app` 拖到“应用程序”，再打开。本包未签名/公证；若系统阻止打开，请按系统“隐私与安全性”的提示允许此应用。Intel Mac 不在本包支持范围内。

## Windows x64
下载 `Ascent-Windows-x64.zip` 并完整解压，运行目录中的 `Ascent.exe`。不要只把 exe 拿出来，旁边的资源与 DLL 都要保留。本试玩包没有代码签名，系统可能提示未知发布者。

## Linux x64
下载 `Ascent-Linux-x64.tar.gz`，解压后进入 `linux-unpacked` 目录，运行 `./ascent-life`。需要有桌面环境和 Electron 运行所需的系统库。Windows/Linux 目前仅验证构建，遇到环境问题请在 GitHub Issues 反馈系统版本和报错。

## 操作
WASD 或方向键移动，拖动鼠标转身，E 查看人生标记，Shift 快走，J 查看生平。网页支持触屏；标题页也可选择“文字版”。

本版本没有 Steam 所有权要求，可离线运行桌面包。正式 Steam 成就、云存档和商店上架仍未完成。
